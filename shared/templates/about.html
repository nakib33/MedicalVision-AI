About MedicalVision AI Suite

🎯 Overview

MedicalVision AI Suite is a comprehensive portfolio of 12 deep learning projects focused on medical image analysis. Built with PyTorch and served through a unified FastAPI web interface, each project demonstrates the application of convolutional neural networks (CNNs) to a different medical imaging modality and disease classification task.

🧠 Explainable AI (XAI)

Every project includes 7 state-of-the-art explainability methods that visualise how the model reaches its prediction:

  • Grad-CAM - Gradient-weighted Class Activation Mapping (Selvaraju et al., ICCV 2017)
  • Grad-CAM++ - Improved localisation for multiple instances (Chattopadhay et al., WACV 2018)
  • Score-CAM - Channel activation weighting without gradients (Wang et al., CVPRW 2020)
  • Vanilla Saliency - Input gradient visualisation (Simonyan et al., ICLR 2014)
  • Guided Backpropagation - Modified backprop for sharper features (Springenberg et al., ICLRW 2015)
  • Integrated Gradients - Path-integral attribution (Sundararajan et al., ICML 2017)
  • Occlusion Sensitivity - Sliding-window occlusion map (Zeiler & Fergus, ECCV 2014)

🏗️ Architecture

Backend Python 3.14+, FastAPI, Uvicorn
Deep Learning PyTorch 2.13, TorchVision, CUDA 12.6
Models EfficientNet-B0/7, ResNet18/50, DenseNet121, Custom CNN
Frontend HTML5, CSS3, JavaScript (Vanilla)
Image Processing Pillow, OpenCV
Visualisation Matplotlib, PDF Report Generation

📄 How to Use

  1. Select a project from the home page
  2. Upload a medical image (drag & drop or click to browse)
  3. Click "Analyse Image" to get a prediction
  4. View class probabilities and confidence score
  5. Browse through all 7 XAI heatmaps in the gallery
  6. Click 🔄 to toggle between heatmap and overlay view
  7. Click on any heatmap to expand it
  8. Download a comprehensive PDF report
